# 猛人输入法 v0.4.8（安卓、Windows）

- Windows 和安卓新增「局域网文件复制粘贴」，默认关闭。双方升级后，连接同一局域网，在各自设备上开启功能并选中已配对的对方。以后每次复制一个文件即可发送。
- Windows 在「设置 → 实验功能」开启，再按 Ctrl+Alt+V，进入「设备」点「允许文件」。发送时在资源管理器选中文件按 Ctrl+C，接收时在目标文件夹按 Ctrl+V。
- 安卓在「设置 → 局域网同步」开启，并勾选「允许与此设备互传文件」。文件管理器支持系统复制时可直接复制，也可点「分享 → 猛人输入法 · 局域网发送」。接收后可在支持文件粘贴的应用中粘贴，或在猛人键盘的「剪贴板」点「保存到下载」。
- 单个文件小于 300 MB，支持空文件、未知后缀及无后缀文件，保留文件名和原始内容。每次选一个普通文件，整个文件夹可先打成 ZIP。
- 文件仅在双方直接相连的局域网内传输。断线后需重新复制，文件内容及文件信息均不进入公网中转、历史补传或第三台设备。普通文字、截图和复制的图片内容继续按原设置同步。
