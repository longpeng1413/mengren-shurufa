# 猛人输入法 v0.5.0（Windows）

- 翻译窗口保留原文格式：从网页、文档复制或选中的多段文字，原文和译文都按原来的分段、空行、缩进和编号显示；`<prompt>` 这类尖括号标签不再被翻坏。
- 翻译窗口按文字多少自动调整大小，长文字不用手动拖；手动拖过窗口大小后就按你的大小来。
- 原文和译文各有自己的朗读倍速；新增循环播放，原文行、译文行和划词卡片上都有「循环」按钮，可选连读 2、3、5、10 次（默认 3 次）。
- 新增划词翻译：在翻译窗口点「取词…」打开后，拖选或双击文字会出现「译」图标，点它弹出卡片。单个英文词显示美式音标、中文释义、考试标签和原形；句子显示译文；短语或译成英文的中文会多一块词典区，列出每个词的音标和释义。卡片可拖边框调大小、拖标题栏移动，内容多时可滚动。
- 新增悬停取词：在「取词…」菜单里选「按住 Ctrl 把鼠标停在词上」或「鼠标停在词上就查」，鼠标下的单词会弹出不抢焦点的卡片，鼠标移开自动收起；程序不提供文字时会用 Windows 自带的文字识别认出单词。
- 「弹出卡片时自动朗读外文」：英文读原文，中文等译文出来后读英文译文。
- 读不到选中文字时卡片会说明原因；剪贴板被别的程序占用时不再静默失败。

单词释义来自开源词典 ECDICT（MIT），美式音标由 CMUdict（BSD）转换，许可证随安装包放在 `assets\wordcard`。

更新后请完全退出并重新打开要使用的程序。Android 当前版本为 0.4.8，本次不变。
