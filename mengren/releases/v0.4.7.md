# 猛人输入法 v0.4.7（安卓、Windows）

- Windows：设置程序「自定义短语」页的「新增…」与「导入、导出」移到最上面，短语多了不用一直往下滚。
- 安卓：在系统安装确认里点了取消后，回到「关于」页再点「立即更新」会重新弹出确认，不用重新下载（以前部分手机取消后按钮就没反应了）。
- 安卓：「关于」页的更新区新增「在 GitHub 下载」，显示发布页地址，点击用浏览器打开，可手动下载安装包。
- 安卓沿用原安装签名，保留设置、配对及已有数据；Windows 保留设置与短语。

本次取消后可重试的修复要到下一次更新时才用得上（本次升级仍由 0.4.6 的更新流程安装）；如这次在确认框点了取消，可在系统设置里强行停止猛人输入法后再点「立即更新」，或在浏览器打开 https://github.com/longpeng1413/mengren-shurufa/releases/latest 下载。
