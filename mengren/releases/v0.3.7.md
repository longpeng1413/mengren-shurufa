# 猛人输入法 v0.3.7

- 私密互传补齐手机到手机、电脑到手机，Windows 也可自动或手动发送。各接收端需在线、已配对、解锁且开启接收；不入普通历史，不离线补发。
- 两端新增“密码框自动填入”：光标已在可识别的密码框时，收到后直接填入。普通输入框支持绑定当前目标、等待一次自动填入，切换目标、锁屏或超时取消。
- 手机收到后在键盘上方直接显示“点此填入”，不再依赖实体快捷键或寻找工具栏；解锁图标可提前准备等待。
- Windows 新增托盘私密发送与等待入口，默认私密发送 Ctrl+Alt+Shift+V；私密输入、发送快捷键均可自定义。
- 快捷键录制支持符号，包括 Ctrl+Shift+?。按住 Ctrl、Shift 再按 /? 键即可；按物理键检测冲突，支持配置保存与重启读取。
- 加强接收权限与锁屏并发撤销，避免禁收后迟到消息重新入槽；修复配对刚完成、在线清单尚未刷新时私密发送失败的问题。

手机与电脑都更新到本版后使用，原配对、中转地址和令牌保留。现有 v0.3.6 中转兼容，不需要改服务器配置。

自动填充依赖系统正确识别密码控件，本软件不判断密码所属账号或网站。无法识别的控件可用明确的等待或私密输入；失败不回退系统剪贴板。已收到但当时没有活动目标时，保留最多两分钟，稍后通过提示或明确操作填入。

三端加密互传、符号快捷键与目标授权已有自动测试；真实公网使用合成身份和内容验证。用户已确认此前手机到电脑流程可用，新版各手机应用、Windows 密码框、管理员窗口和自动填充交互仍需真机验收。
