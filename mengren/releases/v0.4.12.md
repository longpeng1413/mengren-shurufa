# 猛人输入法 v0.4.12（Windows）

- 修复部分笔记本上听写没有反应的问题：麦克风的音频格式不是 16 kHz 单声道时，现在会自动转换后再识别。听写改用 Windows「设置 → 系统 → 声音」里的默认录音设备。
- 听写出问题时，语音面板会说明原因：找不到麦克风、被系统隐私设置拒绝、被其他程序占用、录音中断、没有收到声音（检查静音键）、没有听清，以及离线模型未下载、离线引擎加载失败、豆包未填 API Key。长提示自动换行显示。
- 按住右 Alt / 右 Ctrl / Win 时又按了别的修饰键、点了鼠标或滚动滚轮，不再误开始听写。自定义组合键含 Win 或 Alt 时，松开后不再弹出开始菜单或激活菜单栏。快捷键监听改在独立线程运行，电脑卡顿后不会失灵。
- 翻译窗口在 125% / 150% 缩放的屏幕上首次打开时尺寸正确；翻译失败后可点「翻译」或按 Ctrl+Enter 重试。
- 剪贴板「全部清空」在设备时钟不一致时，已清空的记录不再被同步回来。

听写日志会记录所用麦克风名称、格式和每段录音的电平（不含录音内容），反馈问题时请附上 `%LOCALAPPDATA%\Qingjian\logs` 里当天以 `server` 开头的日志。安装后请完全退出并重新打开要测试的应用。本版只经过本机自动化检查和台式机真实麦克风录音测试，笔记本效果待复测。Android 当前版本为 0.4.8。
