# 猛人输入法 v0.3.5

- 新增 Windows 与安卓跨网络剪贴板同步，可连接用户自有公网中转；局域网优先，失败后回退 WSS。
- 保留六位码配对与端到端加密，支持跨网络配对、在线设备列表和实际连接路线显示；中转断开后自动重连并对账补传。
- 公网仅同步不超过 1 MiB 的文字和链接，不上传图片；中转不保存内容。设备离线期间的记录由本机历史保留，恢复连接后补传。
- 两端新增中转地址和令牌设置；Windows 使用 DPAPI、安卓使用 Keystore 加密保存令牌，不随普通设置导出。默认关闭，不内置个人服务器地址或凭据。
- 修复 Windows 更新下载结束后、安装启动前取消仍可能启动安装器的问题。
- 按用户决定保留现有悬浮条与翻译快捷键，本轮不新增桌面语音入口或多家 API 配置。

在 Windows「设置 → 实验功能」与安卓「设置 → 剪贴板同步」配置自己的中转。两端需要同时在线，安卓仅在输入法进程运行时同步。

已验证本地真实 TCP/WSS 模拟设备的配对、双向同步、过滤、重连和解绑，并使用真实部署的域名完成合成数据公网验收；已编译检查两端软件。尚未执行安卓手机 4G 与 Windows 的实际操作验收，也未覆盖安装正在使用的软件。自动测试和公网探测不能代替真机验收。
