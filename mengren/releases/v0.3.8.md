# 猛人输入法 v0.3.8

- 优化私密互传：在 1Password 正常复制被标记为敏感的密码后自动发送，已直接配对且允许接收的在线设备自动接收，需要填写时再直接填入；无需打开发送页或提前准备接收。
- 移除空槽输入时隐式开启/取消等待，减少反复出现的准备、取消和过期提示；连续按键共用单个输入任务，避免重复填入及争抢。
- 修正安卓敏感复制在发送任务受理前被提前去重的问题；复制监听由应用进程持有，不要求键盘窗口展开，收起或销毁键盘不再清除进程级私密内容。
- 增加逐设备接收确认与确认台数，发送端设备页可区分哪些设备确认收到；慢目标不会再耗尽全局时间导致后续设备被直接跳过。接收确认不代表已经填入。
- 合并安卓重复提示，限制电脑气泡频率并避免积压；旧同步任务的迟到回调不会覆盖当前服务状态。
- 两端保留可选的密码框自动填入，新配置默认按需填入；已有明确保存的开关继续生效。Windows 托盘提供“填入已收到的私密内容”，原有符号快捷键继续可用。
- 更新原设计、隐私说明、跨网络同步说明和定向测试步骤，补齐设置帮助链接。

手机和电脑都更新到本版后测试；原配对、中转地址、令牌及快捷键保留，已有 v0.3.6 中转兼容，无需改服务器。

建议先关闭可选的“密码框自动填入”：从魅族的 1Password 复制一条假密码，不打开猛人发送窗口、不按任何准备键；检查发送端设备页中华为和电脑各自的接收结果，再在两端打开目标输入框填入。详细步骤见 [测试清单](https://github.com/longpeng1413/mengren-shurufa/blob/main/docs/user/help/mengren-testing.md)。

敏感内容仍不进入猛人普通历史；接收端不写系统剪贴板，最多两分钟、各端单次使用，不离线补发。发送端复制仍使用系统剪贴板，无法屏蔽其他有权读取的软件。手机应用进程被系统结束后无法后台接收，自动发送依赖源应用提供受支持的敏感标记。

已完成相关模块自动测试、安卓 Kotlin 与 ARM64 编译和静态检查。本次发布供真实设备复测，不将这些检查当作魅族、华为或每个目标应用已经验收通过。
