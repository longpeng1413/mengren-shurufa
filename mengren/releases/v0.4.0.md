# 猛人输入法 v0.4.0

- Windows 剪贴板改为紧凑小窗口，内容竖排、用滚轮上下查看；短文字卡片减少留白，长文和图片预览限高，原内容完整保留。适配当前显示器工作区和系统缩放。
- 修复 Windows 小键盘输入六位配对码时被当作 Home / 方向键，造成光标移动、数字顺序变化的问题；普通数字键、粘贴和 NumLock 关闭后的导航继续可用。
- 手机和电脑统一使用「自定义短语」名称。所有直接配对且运行本版的设备会自动合并新增短语，支持局域网和现有加密中转；也可点击立即同步。
- 保留输入码、无码条目、分组、换行、权重及启用状态；相同内容不重复，同码不同内容均保留。电脑剪贴板新增短语面板，手机的无码条目也能点击填写。
- 本版同步新增条目；编辑成新内容会追加，删除和排序只影响本机，避免误删其他设备的内容。已在本机删除的旧条目不会被旧快照自动恢复。
- 补充新增设备配对说明、多设备扩容回归及使用文档。

手机、台式机和笔记本都更新至 0.4.0；原配对、中转参数和快捷键保留，现有中转服务器兼容。只加入局域网或看见中转设备不等于配对，新设备仍需与其他目标逐对完成六位码配对。

短语是持久保存的用户资料，请不要把密码存成短语。接收短语不会写系统剪贴板或普通历史；私密密码继续使用独立的两分钟内存槽与单次填写流程。

本版包含合成数据的短语双向与中转测试、去重和本机删除保护、既有普通/私密互传及输入/布局回归。手机后台限制、每个目标应用和覆盖安装仍需真实设备验收。详见 [测试清单](https://github.com/longpeng1413/mengren-shurufa/blob/main/docs/user/help/mengren-testing.md)。
