# 猛人输入法 v0.3.6

- 公网中转支持普通文字、链接和图片，单条小于 100 MB；修复安卓收到图片后不能直接从系统剪贴板粘贴的问题，并避免图片在设备间反复回传。
- Windows 支持复制资源管理器中的单张受支持图片文件后同步；两端统一图片上限，保留像素和解码保护。安卓大图片采用限长暂存导入，减少内存副本。
- 新增私密发送：手机可自动处理已标敏感的复制内容，或用工具栏锁图标手动发送。仅发给在线、已配对且允许接收的电脑；不进入普通同步历史，不离线补发。
- 电脑私密内容只在内存保留两分钟、仅输入一次，锁屏、休眠、退出或解绑清除。默认 Ctrl+Alt+V 有私密内容时直接输入，没有时打开历史面板；设置中可更改快捷键。输入受阻不会回退普通粘贴。
- 明确提示暂停记录会同时停止发送新复制的内容；接收和已有历史仍可用。
- 补齐 GitHub 中转部署、两端配置、100 MB 范围、图片/文件区别、暂停排查及私密功能说明。

服务器和两端均需升级至本版，原配对与设置保留。普通文件和文件夹仍用快传。手动私密发送不会追溯删除此前普通复制已形成的历史。

验证使用自动测试、合成设备与真实域名的加密公网探测；不读取真实密码或真实剪贴板。手机 1Password、实际应用图片粘贴和 Windows 管理员窗口输入仍需真机验收，构建通过不等于这些操作已验收。
