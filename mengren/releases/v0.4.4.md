# 猛人输入法 v0.4.4

- 安卓新增「设置 → 键盘 → 手势 → 自定义上滑符号」：逐字母设置符号、数字或短组合，键面角标和长按符号同步更新；可单键留空恢复或恢复全部默认符号。
- 自定义符号应用于全键盘、英文及双拼字母键；保留双拼声韵母、微软双拼的 Shift 手势和九宫格原有数字手势。
- 安卓新增「设置 → 外观 → 候选词间距」：每侧留白 2–24 dp，默认由原来的 12 dp 缩至 8 dp；拖动时实时预览，可恢复默认间距。候选文字、译文与点击区域按同一布局生成。
- Windows 与安卓版本同步为 0.4.4，沿用原有更新签名与安卓安装签名，保留设置、配对及已有数据。

自动测试和安装包校验不能替代手机上的手感确认。升级后建议先把 A 键上滑改为 @，再拖动候选间距并输入 nihao，检查显示与点击；测试步骤见[测试清单](https://github.com/longpeng1413/mengren-shurufa/blob/main/docs/user/help/mengren-testing.md)。
