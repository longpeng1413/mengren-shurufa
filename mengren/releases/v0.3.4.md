# 猛人输入法 v0.3.4 正式版

- 新增安卓与 Windows 内置更新：自动检查正式版，点击更新即可下载、校验并启动系统安装。
- 新增下载进度与取消；更新清单验签，安装包核对 SHA256 与大小，校验失败停止安装。
- 安卓沿用现有签名，更新保留设置和数据；支持读取系统代理及填写独立更新代理。
- Windows 更新使用原安装目录覆盖升级，保留用户配置，完成后重新启动输入法服务。
- 包含中英互译长按粘贴、有道翻译、豆包两种 2.0 语音模式及安卓云服务功能分配。
- 保留青简来源说明，统一天马图标，提供青简官网、青简 GitHub 与猛人输入法 GitHub 入口。

首次安装本版需要手动安装一次，之后从软件的「关于 → 检查更新／立即更新」升级。
安卓可能要求允许本应用安装更新并确认安装；Windows 可能显示系统管理员确认。

本轮已完成编译、相关自动测试、签名与安装包校验。手机安装确认、Windows 管理员确认及安装后实际使用仍需真机验收。
