## 说话输入

在猛人输入法的「设置 → 语音」选择识别服务。本机离线识别需要先下载模型；使用豆包时请先配置服务密钥。把光标放进可输入文字的位置，切到猛人输入法，按住右 Alt 约 0.4 秒开始说话。松开后稍等，识别完成就会写入光标。录错时按 Esc 取消。录音和识别期间请停留在原来的输入框，切换到别的窗口会取消这一段。

在同一页可以修改长按时间，选择右 Ctrl、Win、自定义组合键或不用快捷键。右 Alt、右 Ctrl 和 Win 短按仍保留原用途。也可以点悬浮状态条的「说」开始听写，再点一次结束。旧配置中已设定的语音组合键仍可使用。若更新前就开着的应用还需要再按一个键才能上屏，关闭并重新打开该应用。

## 翻译和朗读

先在「设置 → 云服务」启用有道翻译或 AI 服务。按 Ctrl+Alt+F 或点悬浮条的「译」，输入原文后停顿片刻会自动翻译。按 Ctrl+Enter 可以立即翻译。中文译为所选外语，外文译为中文；首次使用时跟随支持的学习语言，之后记住你的选择。

翻译窗口默认使用黑色背景。点顶部「背景色…」可以选其他颜色，下次打开会沿用。文字会随底色自动切换为浅色或深色。

点「对调」可将译文放回原文框并重新翻译。「朗读原文」和「朗读译文」使用 Windows 自带的声音，再点同一按钮可以停止。想听某种语言的声音，可在 Windows 设置中添加对应的语音包；缺少对应声音时会尝试系统默认声音。点「复制译文」后即可在其他应用粘贴。

窗口在前台时再次按快捷键或按 Esc 会收起窗口。十分钟内重新打开可继续之前的内容。在「设置 → 快捷键」可以更改或关闭翻译窗口快捷键。原有的选中文字翻译和符号面板翻译仍可使用。
