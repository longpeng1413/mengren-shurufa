## 说话输入

在猛人输入法的「设置 → 语音」选择识别服务。本机离线识别需要先下载模型；使用豆包时请先配置服务密钥。把光标放进可输入文字的位置，切到猛人输入法，按住右 Alt 约 0.4 秒开始说话。松开后稍等，识别完成就会写入光标。录错时按 Esc 取消。录音和识别期间请停留在原来的输入框，切换到别的窗口会取消这一段。

在同一页可以修改长按时间，选择右 Ctrl、Win、自定义组合键或不用快捷键。右 Alt、右 Ctrl 和 Win 短按仍保留原用途。也可以点悬浮状态条的「说」开始听写，再点一次结束。旧配置中已设定的语音组合键仍可使用。更新前已打开的应用可能仍加载旧版输入法。该应用未主动取走识别结果时，服务会再次核对 Windows 键盘焦点，然后向原控件发送 Unicode 文本。

Windows 听写会自动放大偏轻的麦克风声音，正常音量无需额外设置。录音时的波形显示麦克风的实际输入电平。听写使用 Windows「设置 → 系统 → 声音」里的默认录音设备。

按住快捷键期间如果又按了别的键、点了鼠标或滚动了滚轮，这次按键会当作普通操作放行，不会开始听写。

## 听写没有反应时

语音面板会直接说明原因，常见的有：

- 「请先点进输入框，并把输入法切到猛人输入法」：当前窗口的输入法不是猛人，或光标不在可输入的位置。
- 「麦克风被系统拒绝」或「没有收到声音」：打开 Windows「设置 → 隐私和安全性 → 麦克风」，打开「麦克风访问权限」和「允许桌面应用访问麦克风」；笔记本还要检查键盘上的麦克风静音键（通常带麦克风图标，指示灯亮表示已静音）。
- 「没有找到麦克风」：在「设置 → 系统 → 声音 → 输入」选择要用的麦克风。
- 「麦克风正被其他程序独占」：关闭会议或录音软件后再试。
- 「还没下载离线语音模型」或「离线识别引擎加载失败」：在「设置 → 语音」下载模型；仍然失败请重新安装。
- 「没有听清，请再说一次」：录到了声音但没识别出文字，靠近麦克风再说一遍。
- 识别后什么也没写进去、只提示「没有收到声音」：麦克风交出来的是完全的静音。依次检查隐私设置里的两个开关、笔记本的麦克风静音键，以及「设置 → 系统 → 声音 → 输入」里该麦克风的输入音量（可以点「开始测试」看音量条会不会动）。

需要反馈问题时，打开猛人输入法「设置 → 关于 → 日志」，点「打包到桌面」，把桌面上生成的压缩包发给作者（「设置 → 高级 → 日志」也有同样的按钮）。日志里记录了所用的麦克风名称和录音音量，不包含录音内容；配置里的密钥会被抹去。

## 翻译和朗读

先在「设置 → 云服务」启用有道翻译或 AI 服务。按 Ctrl+Alt+F、快速双击右 Ctrl，或点悬浮条的「译」，输入原文后停顿片刻会自动翻译。在其他程序里先选中一段文字再按 Ctrl+Alt+F 或双击右 Ctrl，选中的文字会直接带进窗口翻译（最多 4000 字）。输入框里的文字由输入法直接读取；网页正文、文档这类不能编辑的内容，会改用系统的辅助功能读取，读不到时再替你按一次复制（Ctrl+Insert）取到文字，并把剪贴板原来的内容放回去——这种情况下选中的文字会出现在剪贴板历史里。私密输入框里的文字不读。按 Ctrl+Enter 或点「翻译」可以立即翻译。原文的分段、空行、缩进、行首编号和列表记号会原样保留，译文按同样的分行显示；`<prompt>` 这类尖括号标签不翻译。选中文字带进窗口时，窗口会按文字多少自动调高，最高到屏幕可用高度，长段落放不下时会稍微加宽；文字少时回到默认大小。手动拖过窗口大小后，就只在放不下时再变大。中文译为所选外语，外文译为中文；首次使用时跟随支持的学习语言，之后记住你的选择。

翻译窗口默认使用黑色背景。点顶部「背景色…」可以选其他颜色，下次打开会沿用。编辑区、按钮和文字会跟随底色调整。点「背景色… → 恢复默认黑色」可以回到黑色主题。

点「对调」可将译文放回原文框并重新翻译。「朗读原文」和「朗读译文」优先用电脑里装的系统语音，再点同一按钮可以停止。两个朗读按钮旁边各有一个显示倍数的按钮（如「1.0×」），是朗读速度，可选 0.5× 到 2.0×；原文和译文各用各的速度，比如英文原文放慢听、中文译文照常读，下次打开沿用；鼠标停在上面会有说明。复制英文进来不用对调，直接点「朗读原文」就能听。倍速菜单下面是朗读来源（两个菜单里改的是同一项）：选「自动」（默认）时，电脑里没有某种语言的语音，会联网用百度翻译的发音朗读，目前百度只读中文、英文、日语、韩语，朗读的文字会发给百度；选「只用本机语音」则不联网。窗口底部的小字列出本机和联网各能读哪些语言，两样都不行的语言，朗读按钮会变灰。想让电脑自己读日语、法语、俄语等，在 Windows「设置 → 时间和语言 → 语音」里添加对应语音，重新打开翻译窗口后底部就会列出它。百度发音不是公开服务，可能随时失效，失效时状态行会提示。点「复制译文」后即可在其他应用粘贴。

朗读速度按钮旁边的「循环」按钮（显示「不循环」或「循环 3 次」）可以打开循环播放：每次点朗读，同一段会连读几遍，两遍之间停顿一下；次数可选 2、3、5、10 次，默认 3 次。读的过程中再点同一个朗读按钮会连同剩下的几遍一起停下。划词卡片上也有同样的「循环」按钮，两处改的是同一个设置，下次打开沿用。

窗口在前台时再次按快捷键或按 Esc 会收起窗口。十分钟内重新打开可继续之前的内容。在「设置 → 快捷键」可以更改或关闭翻译窗口快捷键，也可以关掉「双击右 Ctrl」。单按右 Ctrl 照常可用；如果把 Ctrl 设成了中英切换键，双击会切换两次、回到原来的模式。选中文字后快速双击右 Shift（或按 Ctrl+Alt+T），译文会出现在候选框里：回车替换原文，Esc 保留原文。这项要在用猛人输入法打字的程序里用；当前程序没在用猛人输入法时，会改为打开翻译窗口显示译文。微信、WPS 这类程序里，选中的文字会先替你复制一下再翻译。私密输入框里不读。在「设置 → 快捷键」可以关掉双击右 Shift。符号面板翻译仍可使用，只开有道翻译也能用。

## 划词翻译

点翻译窗口顶部的「取词…」，勾选「划词翻译：选中文字后显示「译」图标」后，在网页、文档等地方用鼠标拖选一段文字，或双击一个单词，鼠标旁会出现一个绿色的小「译」图标。只有真的选中了文字才出：拖图片、拖窗口、双击图表或空白处都不会出。点它会在图标下方弹出卡片：

- 选中的是一个英文单词：显示美式音标、中文释义和考试标签（中考、高考、四六级、考研、托福、雅思、GRE），变形词会标出原形（如 running 标「原形 run」）。查词用电脑里的词典，不联网。点「发音」用美式英语朗读。
- 选中的是句子或段落：显示原文和译文，译文走「设置 → 云服务」里开启的有道翻译或 AI 服务。可以分别朗读原文和译文，或复制译文。

选中的是不超过六个实词的英文短语，或者中文译成了这样的英文短语时（如「等待」译成 Waiting），译文下面会多一块词典区，列出每个英文词的美式音标和几行释义；the、and、of 这类虚词不列。卡片会按内容自动长大，最高到屏幕高度的九成，还放不下会加宽，再放不下可以在译文里滚动；也可以拖卡片的四边或四角调整大小，拖卡片顶部的标题一栏移动位置。

点卡片上的「在翻译窗口打开」可以在翻译窗口里看全文、继续修改。点卡片外面、按 Esc 或点「×」会收起卡片。图标不点的话，几秒后或按任意键、点别处时会自动消失；拖动窗口、在桌面和任务栏上拖动不会出现图标。

同一个菜单里还可以勾选「弹出卡片时自动朗读外文」：选中英文单词或英文句子时读原文，选中中文时等译文出来后读译文。如果什么都没读到（例如剪贴板被别的程序占着），卡片会提示「没有读到选中的文字」。卡片下方按钮放不下时卡片会自动加宽。划词翻译开着时，翻译窗口程序会在后台常驻，卡片弹得更快。读取选中文字的方式与翻译窗口快捷键相同：读不到时会替你复制一下，选中的文字会出现在剪贴板历史里。以管理员身份运行的程序里取不到选中的文字。

## 悬停取词

在「取词…」菜单下方选择悬停取词的方式：

- 「按住 Ctrl 把鼠标停在词上」（推荐）：按住 Ctrl，把鼠标停在一个单词上，约 0.5 秒后在单词下方弹出卡片。按 Ctrl 期间按了别的键（例如 Ctrl+C）不会触发；卡片弹出后接着按了别的键，卡片会收起并停止朗读。
- 「鼠标停在词上就查」：不用按键，鼠标在单词上停约半秒就弹出卡片。
- 「关闭」：不悬停取词。

悬停弹出的卡片不会抢走输入焦点，不影响正在打字或阅读的程序；鼠标离开单词和卡片后会自动收起，按着鼠标键拖动时不会触发。卡片内容和划词翻译一样：英文单词显示音标和释义，其他文字显示译文；开着「弹出卡片时自动朗读外文」时同样会自动朗读。关掉卡片（或翻译窗口）会立即停止它的朗读，开着循环播放也不会再读下一遍。

取词时先向程序询问鼠标下的文字（网页、Word、记事本等都支持）；程序不提供时，会截取鼠标附近一小块屏幕，用 Windows 自带的文字识别认出单词。识别英文最准的做法是在 Windows「设置 → 时间和语言 → 语言和区域」里添加英语，并勾选它的「光学字符识别」。截图只在这台电脑上识别，不会上传。

单词卡片的释义来自开源词典 ECDICT，美式音标由 CMUdict 转换，许可证见安装目录的 `assets\wordcard`。
