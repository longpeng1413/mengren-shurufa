本页说明猛人 Windows/Android 的当前行为；上游其他平台见各自说明。基础拼音转换、词库查询、本地学习和随包译词在设备上完成。开启云服务、语音或跨设备同步后，相应内容会按该功能的规则离开本机，不能笼统理解为“所有内容永不联网”。

v0.3.7 私密互传在真实设备上出现未送达和提示混乱，当前正在处理；下文的数据边界是当前设计与实现约束，不表示所有应用和设备已完成验收。

## 什么时候联网

| 功能 | 发送到哪里 | 内容范围 |
| --- | --- | --- |
| AI 服务 | 用户选择的服务商 | 开启的联想、问字、译词补充等请求，见 [AI 服务](../cloud/index.md) |
| 有道翻译 | 有道 | 本次待翻译文字，独立于会员和其他大模型配置 |
| 安卓语音 | 用户配置的豆包语音服务 | 本次录音或语音流 |
| 普通剪贴板同步 | 已配对设备，直连或经自有中转 | 普通历史中的文字、链接和图片，可离线对账补传 |
| 私密互传 | 直接配对、在线且允许接收的设备 | 本次临时私密文字，不进普通同步历史，不离线补发 |
| 检查与下载更新 | 猛人 GitHub 发布渠道 | 请求版本索引、签名和安装包，不上传输入或剪贴板正文 |

有道、会员和语音凭据分别配置，不能据一个连接测试结果推断其他服务已可用。普通输入和同步不依赖这些云服务凭据。云服务详见 [猛人服务说明](../cloud/mengren-services.md)。

## 同步与自有中转

同步默认关闭。启用局域网发现时，同网设备可见设备名和电脑名或手机型号，不应把秘密写入设备名。复制内容通过配对后的加密通道传输，普通历史可能经共同配对设备转发，配对网络中的设备都应可信。

只有局域网直连不经过服务器；跨网络回退时，自有中转转发端到端密文，可见设备公钥标识、在线状态、来源 IP、连接时间与流量等元数据，看不到剪贴板正文。中转不落消息、不建离线队列，但会保存服务证书与运行日志。公开源码不含维护者个人地址或令牌。

普通文字、链接和图片单条小于 100 MB，收到的普通内容会进入本机历史和系统剪贴板。私密正文最多 16 KiB，规则不同，详见 [同步与私密输入](mengren-relay.md)。

## 私密输入的边界

私密接收路径不写本软件普通历史或接收端系统剪贴板，接收为单个内存槽，最多两分钟、各接收端单次使用。锁屏、灭屏、休眠、关闭接收、退出或解绑会撤销相关内容和权限；不经第三台设备转发，不离线补发，输入失败不回退系统粘贴。

源应用复制秘密后，源系统剪贴板仍由源应用管理。把普通文字事后手动私密发送，不会追溯删除已形成的源普通历史。

自动填入依据系统密码框标记，不识别密码所属账号或网站。被选中的目标应用会得到输入正文；本功能不提供对目标网站、管理员软件或恶意本机程序的隔离。系统接口与目标应用产生的字符串副本也不承诺全部可擦除。已有密码管理器的登录项仍可使用其原有自动填充。

## 密码框与输入记录

在系统可识别的密码框和私密输入框中，不学习输入习惯、不记生词本或输入日志、不向 AI 发送内容；密码按键直接交给应用。自定义控件是否正确声明类型、Linux 的私密标记支持，以及各手机 ROM 的行为需分别核实。

本机保存设置、学习数据、生词、统计、普通剪贴板历史与图片、导入词库、主题、输入日志和运行日志等。不是所有文件都是纯文本；位置和导出方式见 [数据文件与日志](../advanced/data-files.md)。会员凭据、中转令牌和服务密钥按对应平台的安全存储方式保存，不随普通配置导出。

API 用量仅记录计数，小时文件会合并同小时记录；保留天数和硬总量上限尚待补齐，不将合并机制说成自动淘汰旧统计。

## 输入日志

输入日志保存本机上屏与候选等诊断信息，不自动提交给维护者。关闭或清空入口见「设置 → 高级」；测试前可关闭输入日志。密码框与私密接收正文不应进入这些日志。

## 运行日志

运行日志按天保存，保留七天；默认主要记录事件和计数，详细模式可能记录更多输入诊断，排查后应关闭。Android 可记录上次进程退出原因，便于区分动画结束与系统结束进程。日志保护仍需实际应用回归，反馈前检查文件，不公开真实密码、密钥或令牌。反馈方式见 [反馈问题](feedback.md)。

## 检查更新

猛人版本使用独立 GitHub 正式发布与专用签名，不从上游青简更新源获取本产品安装包。默认每日自动检查，可关闭；下载由用户操作发起，系统按平台要求显示安装确认。请求不携带输入、剪贴板正文或账号凭据，但服务端仍可见网络连接的 IP 等通常元数据。

更新失败、取消和残片处理见 [更新说明](mengren-updates.md)。下载验证通过不等于系统覆盖安装已验收，安装后的版本和设置保留按 [真机清单](mengren-testing.md) 检查。
