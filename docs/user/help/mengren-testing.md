## 0.4.4 重点回归

1. 安卓「设置 → 键盘 → 手势 → 自定义上滑符号」，把 A 改成 @、Q 改成 9。回输入框看角标，上滑对应键应直接输入；切英文/双拼仍生效。清空某个键恢复语言默认，恢复全部需确认。九宫格上滑数字不变。
2. 安卓「设置 → 外观 → 候选词间距」，在 2、8、24 dp 间拖动，观察即时预览。输入 nihao 并横滑候选，点前后多个词应选中正确文字；深浅色和候选字号切换后仍正常。恢复默认回到 8 dp。
3. 关闭再打开设置和键盘，确认自定义符号与间距保存；升级保留原有设置、配对和数据。真实手机手感尚待确认。

## 0.4.3 重点回归

1. 复制假验证码 `001234`，打开其他应用输入框，猛人键盘上方应出现按钮；点击输入完整六位且保留前导零。使用或点叉后不重复出现，再复制一次可重新显示。
2. 复制 `【测试】验证码001234，五分钟有效。`，检查建议填入数字；普通手机号、完整卡号、多个不同验证码不应被截成某个数字码。收到真实短信后，也可自行测试通知里的“复制验证码”，无需提供短信或真实验证码。
3. 复制后换应用、收起/重开键盘，五分钟内未使用的内容仍可建议；超过五分钟不建议，重新复制才开始新一轮。已有拼音候选时应优先正常选词。
4. 复制密码管理器标记敏感的测试内容，按钮不应显示明文；跨设备私密接收继续优先使用原提示。点击只输入一次，不自动提交登录。
5. 安卓“高级 → 打包日志”分别保存/分享，Windows 新旧设置分别导出日志，默认包名应为 `mengren-shurufa-logs-日期.zip`。安卓数据备份为 `mengren-shurufa-data-日期.zip`。
6. 更新后检查启动器、输入法列表、设置/托盘/任务栏和旧版设置的名称及天马猛图标；切换英文界面查看标题和导出名。关于页的青简来源、官网和 GitHub 应保留。

## 0.4.2 重点回归

1. **魅族私密提示**：两端保持同步、私密接收和原配对，电脑解除暂停记录。电脑复制一条假密码至魅族，手机打开输入框。提示出现后立即点功能入口、收起键盘、重新展开、输入拼音并点选候选，均不应等两分钟。点提示的叉号，本机待用内容应消失；重新复制后可再次收到，点提示填入一次。接收端系统剪贴板和普通历史不应出现假密码。
2. **工具栏排序**：功能面板 → 定制工具栏。长按上方已选按钮，拖到另一位置或另一行，松手后点 ✓。重开检查顺序；再编辑并用系统返回放弃，原保存顺序应保留。拖动到边缘可滚动查看。
3. **设备名同步**：参与的手机和电脑都升级至 0.4.2。在任一方改中文或中英混合名字，另一方原已配对列表应在同步后更新。离线改名后恢复在线再观察；不解除配对，不重新填写中转令牌。重启后名字与配对应保留。

若失败，记录时间、两端版本、设备别名、目标应用及哪个步骤失败。日志只需阶段和结果，不公开真实密码、密钥或私人部署信息。

## 后续需要排障时的定向步骤

以下作为排障参考，并非要求重新执行全部验收。

- 私密发送时，已直接配对且允许接收的在线设备分别显示投递结果；一台离线不应阻止其他在线设备。接收确认不等于已填写。无需预先准备接收、打开私密发送窗口或按发送快捷键。
- 已收到内容时，重复点击/快捷键仅能填入一次；无内容时不应排队弹出等待或过期提示。超过两分钟、锁屏、禁收、退出或解绑后，旧内容不可填入；私密内容不离线补发。
- 使用可选“密码框自动填入”时，接收当时已有活动密码框才尝试填入。收到时没有目标，之后打开密码框不应自行补填；不匹配网站或账号归属。默认先以按需填入排查。
- 回归移动网络时，一端关闭 Wi-Fi 用移动数据，另一端留在家庭网络，确认中转已连接，再复制普通文字、链接和小图片。普通内容可从仍保留的历史补齐，私密内容需要重新复制后发送。
- 回归后台时，手机切到其他应用、亮屏放置后从电脑复制；记录后台到达或唤起键盘后补齐，不强行停止输入法进程。无需改路由器或删 DNS。
- 新设备先逐对完成六位码配对；仅出现在附近/中转名单不代表已配对。没有三台设备限制。

发送端复制后，其他有权限的软件仍可能读取源系统剪贴板，这是已接受的流程边界。异常清理隔离核查由开发者负责，不要求用户删文件或重装。配置与数据边界见[同步说明](mengren-relay.md)及[当前版本范围](mengren-freeze.md)。
