本清单适用于 0.4.1；0.4.0 新增项继续有效。先通过「关于 → 检查更新」升级并确认安装后的版本，原配对与中转配置保留。用户已经确认的项目不重复标为失败；所有检查使用假密码，不发送真实凭据。冻结后可自行验证，是否恢复修复由用户决定。

## 私密流程回归（魅族到华为和台式机已有用户确认）

1. 两端开启同步和私密接收，发送模式为自动；设备之间直接配对。电脑解除暂停记录。先关闭可选的“密码框自动填入”。
2. 魅族的 1Password 建立测试条目并复制假密码；不要打开猛人发送页，不按发送快捷键，也不提前在华为或电脑准备等待。
3. 在发送端同步设备页检查华为、电脑各自是否显示本次已接收。确认台数不能替代逐设备结果，“已接收”也不代表已经填入。
4. 华为随后打开普通输入框，点击猛人键盘上方的私密内容提示；电脑选好输入框，使用私密输入快捷键，或从托盘选择“填入已收到的私密内容”。应各输入一次。
5. 核对接收端普通剪贴板及猛人历史没有假密码；再次填入不能重复旧密码。所有操作应在两分钟内完成。

若失败，记录复制与操作时间、设备别名、两端版本和应用、各设备接收状态；日志只需阶段与结果，不发送真实密码。发送端复制后其他有权限的软件仍可能读取，这是已接受的边界。

## 重复操作与迟到事件

- [ ] 没有私密内容时，连续点手机解锁图标、连续按电脑独立私密输入键，不出现准备、取消或等待过期提示，不会稍后无确认填入新内容。
- [ ] 已收到一条时，连续点击/按键只填入一次；重复提示不会长时间排队出现。默认共用 `Ctrl+Alt+V` 在没有内容时仍可打开历史。
- [ ] 电脑按住修饰键触发输入后改变目标窗口，输入应失败而不写剪贴板；失败不能清除期间新收到的另一条。
- [ ] 收到后超过两分钟、锁屏、关闭接收或解绑，再填入都不能使用旧内容。
- [ ] 目标锁屏/禁收时发送，设备页不误报成功；解锁后不补发。重新复制一条新内容才能开始新投递。
- [ ] 一台已配对设备离线、另一台在线时，在线端仍能收到，状态按设备区分。

## 快捷键、后台和普通同步

- [ ] 录制 `Ctrl+Shift+?`，保存后退出重开仍有效；发送快捷键与输入/历史快捷键不能冲突。
- [ ] 手机键盘收起、应用进程仍运行时复制与接收正常。系统结束整个进程后无法接收，不把进程已结束当作后台可达。
- [ ] 移动网络与宽带下普通文字、链接、图片双向同步；断线后普通历史补传，私密内容不补传。
- [ ] 安卓翻译框长按粘贴、有道翻译、豆包两种语音模式、删除手势及内置更新入口回归。
- [ ] 曾反馈的橙色光圈另记时间与进程状态，关闭同步霓虹提示后观察，不能把动画消失等同进程退出。

自动测试不替代以上真机检查；完整设置见[同步说明](mengren-relay.md)。

## 0.4.0 新增验证

1. 手机、笔记本和台式机均检查更新至 0.4.0；已配对名单、中转配置和短语应保留。未配对设备先逐对配对。
2. Windows 显示一组真实配对码，在另一电脑用小键盘逐位输入；确认输入顺序与显示码一致。另在未提交的输入框试 `789456`、`123456`、退格、左右键、选中替换和粘贴；这些示例数字不是固定配对码。
3. 呼出电脑剪贴板，应是紧凑小窗口、内容竖排；滚轮上下查看、搜索、点选及上下键选择后回车粘贴。检查四屏和笔记本的缩放下都在当前屏幕内。
4. 电脑新增 `csaa → 测试短语甲`；手机新增 `csbb → 测试短语乙`；检查所有直接配对设备自动出现，也可点「立即同步」。手机另建一个分组和无码条目，电脑短语面板应能点选。
5. 添加同码不同内容，应均保留；重复同步不增加重复条目。本机删除一条后同步，不应重新出现；本版不向其他设备传播删除。断开某一设备，其他设备新增，重新上线后检查补齐。
6. 回归普通文字、图片及假密码私密输入；短语收到时不应覆盖系统剪贴板，不能出现真实密码或真实凭据作为测试素材。

自动测试只验证合成数据与代码行为；实际手机后台限制、目标应用和系统覆盖安装仍需真机验收。

## 0.4.1 中文命名与冻结验收

1. 安卓进入同步设置的「设备名」，用中文键盘输入「猛人的魅族手机」，确认可正常组词、选词和保存；再尝试中英混合名称。
2. 返回后重新进入设置、重新启动应用，名称应保留；留空应恢复默认名称，取消编辑应保持旧名称。
3. 新发现/新配对设备应支持中文；已有配对列表可能仍显示旧名称，不据显示名判断身份，也不要求为改名清除原配对。
4. 回归原地址、应用 ID 和密钥输入框：设备名改为普通文本，网址与密钥保持各自输入方式。
5. 0.4.1 之后停止新增开发。未完成功能与待验收的完整清单见[冻结状态](mengren-freeze.md)，不把打包或下载验证当作手机已验收。
