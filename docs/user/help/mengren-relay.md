从 v0.3.5 起，Windows 与安卓可以使用自己部署的公网中转。仍然优先局域网直连，连接不上时再尝试中转。默认关闭，需要两端都开启剪贴板同步并配置相同的中转地址与访问令牌。

## 一次性设置

1. Windows 打开「设置 → 实验功能」，开启猛人剪贴板、剪贴板同步和「跨网络剪贴板同步」。填写自己的中转地址和访问令牌。需要查看已存令牌以配置手机时，点击「显示已存令牌」；再次点击或离开设置窗口即可隐藏。
2. 安卓打开「设置 → 剪贴板同步」，开启同步和「不在同一网络时使用中转」，填写相同的地址与令牌。
3. 地址示例为 `wss://relay.example.com:8443/v1/clipboard`。必须包含自己的域名、实际端口和末尾路径，不能填健康检查地址；公网只接受加密的 `wss://`。
4. 在两端的设备页确认「中转已连接」。如以前已经配对，配对关系继续使用；没有配对时，在一端显示六位配对码，另一端点击中转在线设备并输入该码。输错一次需要重新生成。

中转在线设备配对前以设备编号末尾区分；配对完成后显示对方实际设备名。已连接设备如果最近一次通过公网同步，状态旁会显示「公网中转」。电脑设备页位于猛人剪贴板面板内。

## 使用与限制

- 两端同时在线时，新复制的普通文字和链接自动同步。跨网络不传图片与大文件，这些继续使用猛人快传。
- 单条文字最多 1 MiB；局域网原有的图片同步保持原样。目标设备离线时，中转不保存内容，恢复连接后由设备按本机仍保留的剪贴板历史补传。
- 安卓只在输入法进程运行时同步，不新增常驻通知；进程被系统结束后，下次弹出键盘或打开设置时恢复并补传。电脑休眠或没有网络时无法接收。
- 先尝试局域网可能需要约三秒，然后才进入公网连接；不保证首次连接或网络切换时两秒内到达。
- 访问令牌加密保存在当前设备上，不随普通设置导出；两端需要分别填写。删除中转令牌不会删除本机剪贴板历史或配对关系。
- 中转仅转发端到端加密的数据，六位配对码和剪贴板正文不会以明文发送给中转。服务器可以知道设备编号、在线状态和流量大小。

## 连不上时

检查两端地址、端口、令牌是否一致，域名是否解析到自己的服务器，证书是否有效，服务器是否放行该 HTTPS 端口。国内服务器通常可以直连；分应用代理或 VPN 影响连接时，检查是否允许本应用直接访问中转。

自建服务的构建、部署与安全边界见仓库中的 `mengren/relay/README.md`。本项目不提供共享的公共中转，不能使用别人的域名或凭据。
