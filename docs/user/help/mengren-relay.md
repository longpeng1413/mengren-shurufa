Windows 与安卓优先局域网直连，连接不上再尝试自己的公网中转。两端都需要开启同步、配置相同中转并完成六位码配对。翻译、语音和 ChatGPT 登录与剪贴板同步互相独立。

## 一次性设置

1. 先按 [服务器部署说明](https://github.com/longpeng1413/mengren-shurufa/blob/main/mengren/relay/README.md) 部署中转，准备域名、端口和随机访问令牌。
2. Windows「设置 → 实验功能」开启猛人剪贴板、剪贴板同步和跨网络同步，填写中转地址与令牌。点击「显示已存令牌」可配置手机，离开窗口自动隐藏。
3. 安卓「设置 → 剪贴板同步」开启同步及中转，填写同样参数。例如 `wss://relay.example.com:8443/v1/clipboard`，末尾路径不能省；不能填 `/healthz`。
4. 两端设备页均显示中转已连接后，在一端显示六位码，另一端点击在线设备并输入。输错一次要重新生成。已经配对的设备无需重新配对。

请将服务器、Windows 与安卓都升级至 v0.3.6 或更新版本。旧版中转仍有小流量限制，旧版客户端不会接收公网图片。

## 文字、链接和图片

- 单条内容必须小于 **100 MB（100,000,000 字节）**，局域网与中转都支持普通文字、链接和图片。文字在客户端另有限制：最多 100 万字符，超长文章不宜用剪贴板传输。
- Windows 复制位图、截图或资源管理器中的单张受支持图片文件可以同步。安卓通过图片应用的「复制图片」复制；只是复制图片地址时，同步的是链接。多文件、文件夹、压缩包和其他普通文件继续使用快传。
- Windows 图片还受 4000 万像素的解码保护限制，编码后的 PNG 也须小于 100 MB。收到手机图片后可在电脑粘贴；手机收到的图片通过系统图片剪贴板提供给支持粘贴图片的应用。
- 普通同步写入本机剪贴板历史。目标离线时，服务器不存消息，设备恢复在线后从双方仍保留的历史补传。手机与手机之间也可同步。
- 安卓在输入法进程运行时同步，系统结束进程后，下次弹出键盘或进入设置恢复。没有新增常驻通知。电脑休眠时无法接收，首次局域网回退可能需要数秒，大图片时间取决于带宽。

## 私密互传与自动填充

v0.3.7 起，手机与手机、手机与电脑均可双向私密互传。**发送端和接收端都升级到 0.3.7**；原配对、中转地址和令牌继续使用，已有 0.3.6 中转兼容。

两端同步设置都提供私密发送方式（自动及手动、仅手动、关闭）、私密接收开关和“密码框自动填入”开关。默认开启自动发送已标敏感的内容，以及接收后的密码框自动填入；两项可单独关闭。只发给此刻在线、已配对且允许接收的设备，手机灭屏或设备锁定时不接收，没有接收端会提示失败，稍后上线不会补发。

### 手机接收怎么用

1. **密码框自动填入**：在接收手机打开目标密码框，保持猛人键盘显示；另一台手机或电脑复制已标敏感的测试密码，接收后自动填入，不需要快捷键。
2. **收到后点一下填入**：收到时没有活动密码框，打开目标输入框后，键盘上方会显示“私密内容已到 · 点此直接填入”。点一下即可，不需要先复制或长按粘贴。
3. **普通输入框预先等待**：先点键盘解锁图标“私密输入”，在没有内容时会为当前框准备两分钟等待。再从另一设备发送，收到后填入这个框。再次点提示、切换输入框、收起键盘或锁屏会取消等待。

工具栏锁图标是发送、解锁图标是输入；自定义过工具栏时可在“定制工具栏”添加。收到后的上方提示不依赖自定义工具栏是否包含图标。正在组拼音或编辑翻译原文时，先结束该操作再用私密输入。

### 电脑接收怎么用

- 光标已在系统能识别的密码框时，收到后自动填入；可在“设置 → 实验功能”关闭此行为。
- 普通输入框可从猛人剪贴板托盘右键选择“等待私密填入当前输入框”；绑定成功后从另一设备发送即可，切换控件会取消。不能识别的自定义控件可使用私密输入快捷键。
- 私密输入默认 **Ctrl+Alt+V**，仍与历史面板共用：有内容时输入一次，没有时打开历史面板。改为独立组合后，无内容时按该键可准备当前框的一次等待。

### 发送与自定义快捷键

手机在密码管理器复制被标为敏感的文字可自动发送，也可点击锁图标或同步页的“私密发送”。电脑支持同样的敏感标记自动发送，也可从托盘选择“私密发送当前剪贴板”，或按默认 **Ctrl+Alt+Shift+V**。

电脑“设置 → 实验功能”可分别录制私密输入和私密发送快捷键，支持字母、数字、符号。例如 **Ctrl+Shift+?**：在录制框中按住 Ctrl 和 Shift，再按 `/ ?` 那颗键。发送键不能与输入键或历史面板键冲突；输入键与历史面板键仍允许共用。

### 保存与使用边界

私密内容最多两分钟、各接收端仅能输入一次；再次收到会替换未使用的内容。锁屏、灭屏、休眠、关闭接收、退出或解绑会清除。不会写入系统剪贴板或本软件普通历史，发送后也不会自动转发到其他设备。

手动私密发送不会追溯删除此前普通复制已形成的历史。需避免历史时，使用密码管理器敏感标记；测试普通便笺里的假密码时，可先关闭普通记录。手机原剪贴板仍由原应用管理。

自动填充按系统的密码框标记判断，不识别这段密码属于哪个账号或网站；请把光标放在正确的目标。部分自定义控件不提供标记，管理员窗口也可能阻止输入，此时使用明确的等待或私密快捷键。已消费但输入失败的内容需重新发送，不会回退普通粘贴。单条最多 16 KiB，不接受换行、Tab 等控制字符。

已有 1Password 登录项，仍可优先使用其原有自动填充。这里负责临时跨设备内容，相关方案比较见 [私密交互设计](../../design/private-transfer.md)。

## 收不到时

电脑「暂停记录」会停止记录和发送新复制内容，已有历史仍可查看，也仍能接收其他设备内容。设备页会显示暂停说明；在托盘右键菜单恢复记录后再复制测试。

确认两端地址、令牌相同、同步开启且已配对。检查域名 A/AAAA、证书与实际 HTTPS 端口；不用 IPv6 时不要配置无效 AAAA。健康地址 `https://relay.example.com:8443/healthz` 应返回正常。代理/VPN 需允许本应用访问中转。图片还要确认复制的是图片内容且目标应用支持图片粘贴。

访问令牌在 Windows 用 DPAPI、安卓用 Keystore 加密保存，不随普通设置导出。中转只转发端到端密文，可以看到设备编号、在线状态和流量大小。本项目不提供共享公共中转，公开源码不包含作者的服务器地址或凭据。
