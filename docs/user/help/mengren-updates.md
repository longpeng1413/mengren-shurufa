猛人输入法的正式安装包发布在[猛人输入法 GitHub Releases](https://github.com/longpeng1413/mengren-shurufa/releases/latest)。0.3.4 是首个带内置更新的版本，需要先手动安装一次；之后可直接在软件内更新。

## 检查与安装

在安卓的「关于」、Windows 设置的「关于」页，点击「检查更新」。发现新版后会显示版本与更新说明，点击「立即更新」即可下载。下载时显示进度，可以取消；下载完成且校验通过后自动启动系统安装确认。

安卓首次更新可能要求允许猛人输入法安装应用。允许后返回软件，继续确认本次安装。在系统安装确认里点了取消，回到「关于」页再点「立即更新」会重新弹出确认，不用重新下载（0.4.6 及更早的安卓版在部分手机上取消后按钮没反应，可在系统设置里强行停止猛人输入法后重试，或用下面的 GitHub 地址下载安装）。「关于」页的「在 GitHub 下载」显示发布页地址，点击用浏览器打开，可手动下载安装包。Windows 可能显示管理员确认。按系统提示完成即可；更新保留词库、学习数据、账号和设置，不需要先卸载。

默认每天自动检查一次正式版，只提示新版本，不会在打字时强行安装。可以关闭自动检查，再手动检查更新。

历史验证包括 v0.3.7 的两端检查、完整下载、签名与摘要校验，以及 v0.3.8 私密投递的用户确认；这些结果不替代当前版本的系统安装与设置保留检查。v0.4.0 修复 Windows 小键盘配对码输入，并加入自定义短语同步和紧凑窗口；数字输入码短语则从 v0.4.6 起支持，参与同步的设备需同时升级至 0.4.6 或更新版本。当前版本 v0.4.7 的功能及检查步骤见[版本状态](mengren-freeze.md)与[真机测试清单](mengren-testing.md)。

## 网络与校验失败

使用分应用代理时，将猛人输入法加入允许名单。安卓读取系统代理，也可在「关于」页填写独立更新代理；Windows 使用系统代理。连接失败后可重试。

若提示更新签名或安装包校验失败，软件会停止安装。重新检查并下载，仍失败时请反馈。下载的旧安装包和残片会从软件缓存中定期清理，不影响用户数据。

更新检查不需要登录 ChatGPT 或填写有道密钥，也不会发送输入内容、剪贴板或账号凭据。

跨网络剪贴板的配置与配对见[跨网络剪贴板同步](mengren-relay.md)。

## 0.4.2 恢复开发

用户已取消 0.4.1 冻结。本版合并安卓私密到达提示交互修复、工具栏长按拖动排序、已配对设备名称自动同步与受管暂存清理核查。名称同步需参与设备均升级至 0.4.2；更新保留配对和原有设置。移动网络、手机后台、锁屏等既有验收按用户反馈记录，休眠不再单列要求。

本机交付目录每个平台只留最新包，新包成功校验后将旧包送回收站；GitHub 历史版本保留。当前范围与待确认项目见[版本说明](mengren-freeze.md)，真机界面修复需安装新版后复测。

## 0.4.3 名称与验证码建议

修正两端日志导出默认文件名、遗漏窗口/外语名称与 Windows 程序属性，核对现有天马猛图标入口。安卓新增复制验证码后的点击填入建议；实际使用见[安卓说明](../platforms/android.md#复制验证码后填入)。更新保留原应用签名、配对、短语和设置，不必清除数据。
