0.4.1 是本轮收尾版本，修复安卓设备名不能输入中文的问题。发布后按用户要求暂停开发；现有输入、翻译、同步和检查更新仍可使用。冻结不代表所有原计划功能均已完成或所有设备均已验收。

## 已确认与仍需验证

用户已确认安卓删除手势、有道翻译、普通文字互传、魅族向华为和台式机私密发送，以及电脑配对码数字输入正常。小剪贴板已在实际桌面窗口验证竖排和上下滚动。

仍需在自己的设备验证：中文设备名保存和重启保留、自定义短语跨设备新增与离线补齐、新笔记本逐对配对、各应用图片粘贴、手机后台与休眠恢复、密码框填写、会员续期和豆包语音、系统更新安装及设置保留。步骤见[真机清单](mengren-testing.md)。

## 冻结时的范围

| 项目 | 当前边界 |
| --- | --- |
| 自定义短语 | 自动合并新增；删除、排序和已有条目设置不传播到其他设备 |
| 设备名 | 支持中文；已有配对列表可能保留配对时名称，自动刷新旧名字尚未完成；设备身份和同步不受改名影响 |
| Windows 扩展 | 多服务分配、额外语音入口和悬浮窗改造按用户决定暂缓 |
| 文件传输 | 同步普通文字、链接与单张图片；任意文件和视频继续使用快传 |
| 私密内容 | 发送端正常复制，接收端不写系统剪贴板；单次使用、两分钟过期，不是密码管理器的账号匹配 |
| 用量与清理 | 用量只有合并机制，未完成长期保留上限；部分受管暂存已清理，全部异常路径尚未核查 |
| 橙色闪光 | 尚未确认原因，保留为未解决反馈 |

不需要为测试重新填写真实密码或公开服务密钥。发现问题时记录版本、设备、应用及操作，反馈后由用户决定是否恢复开发。
