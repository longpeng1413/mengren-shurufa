用户已取消 0.4.1 的冻结，当前版本为 0.4.4。旧冻结记录保留为历史，现以本页和[测试清单](mengren-testing.md)为准。

## 已确认通过

安卓删除手势、有道翻译、豆包录音识别、普通文字互传、移动网络、手机后台、锁屏、自定义短语同步、电脑小剪贴板、中文设备名输入和电脑配对码数字输入已有用户确认。魅族到华为/台式机及电脑到安卓的私密传输已确认，但魅族收到后操作卡住是独立交互缺陷。

## 0.4.2 的改进

- 私密提示保留功能与收起入口，叉号丢弃本机待用内容；开始打字时候选继续正常选择，不用等两分钟。
- 定制工具栏的已选按钮可以长按拖动排序；点 ✓ 保存，系统返回放弃此次编辑。
- 配对设备双方升级后，中文或英文改名会经认证同步至原配对列表，不更换身份、不用重新配对。
- 更新和图片导入的受管残片清理增加隔离验证，更新缓存不会按扩展名删除无关文件。

上述代码和工程验证不替代魅族/华为以及不同目标应用的新版本使用验收。流式语音和会员续期等没有单独取得同等确认。电脑休眠未单独验证，用户已决定不再要求该项验收。

## 已接受的范围

自定义短语同步新增条目，删除和排序仅影响本机；数字前缀补全保留为后续需求。桌面多服务、额外语音入口和悬浮窗扩展暂缓。长期用量上限和统一存储占用展示按用户决定不进入本轮，现有统计、条数控制和清空功能继续保留。橙色光圈确认为正常提醒，不再排障。

中转日志采用已确认的 50M / 10 天规则；服务不保存消息正文，规则管理的是运行日志。隐私、私密内容期限和普通历史边界见[隐私说明](privacy.md)。

0.4.3 另已交付安卓复制验证码建议、日志/备份默认文件名和遗漏品牌名称修正，活动图标及 Windows 产品属性已核对。当前范围见[0.4.3 记录](../../plan/resume-043.md)，验证码真机步骤见[测试清单](mengren-testing.md)。

0.4.4 新增安卓逐字母上滑符号自定义和候选间距滑块（实时预览、恢复默认）。当前范围见[0.4.4 记录](../../plan/resume-044.md)，手机上的交互手感需按[测试清单](mengren-testing.md)确认。
