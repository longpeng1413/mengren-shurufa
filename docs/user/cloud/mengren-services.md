当前快捷翻译使用有道，用户已确认安卓可用。Windows 保留现有有道和会员入口，新增桌面多服务分配、语音入口与悬浮窗改造暂缓；下文的多服务分配和两种豆包语音模式是安卓功能。会员完整生命周期、语音效果、翻译粘贴和电脑登录入口仍需真机回归。

在 Windows 的「云服务」页、安卓的「云端大模型」页，点击 ChatGPT 登录会打开默认浏览器的授权网页。浏览器授权通过后，可以使用账号允许的会员用量。云联想仍需单独开启；仅登录不会自动发送平时输入的内容。Windows 完成或失败时会弹出提示，回到设置页即可看到更新。

会员请求在退出登录、登录过期或额度不足时停止，不会自动转到其他收费服务。手机使用分应用代理时，把猛人输入法加入允许名单；也可以填写代理地址，留空跟随系统。

## 安卓按功能选择服务

「功能使用的服务」可以分别指定云联想与整句补全、问字、快捷翻译与选中文字翻译、译词补充使用哪家服务。提供 DeepSeek、OpenAI API、火山方舟和自定义服务，每家分别保存地址、模型、密钥和代理；升级前的配置保留在「原有兼容服务」。

在「编辑服务」中选择一家，填入该服务自己的密钥，点「获取模型列表并选择」或手动填写模型名称，然后测试连接。ChatGPT 会员的模型列表放在登录区域，与 OpenAI API 的密钥和模型分开。

某项服务未配置或请求失败时，该功能暂停，不会借用其他服务的密钥。各功能开关可独立设置。

## 有道与粘贴翻译

有道翻译不需要登录 ChatGPT。在同一页面填写有道的应用 ID 和应用密钥，再打开有道翻译开关。应用 ID 与 API Key 不同；密钥框留空保留已存密钥。安卓可点「测试有道翻译」单独检查有道，其他服务的连接测试在各自编辑区域。

有道使用有道账户自身的用量，优先直连国内接口。启用后，选中文字和快捷翻译交给有道；联想、问字与译词补充使用各自选择的 AI 服务。密码框中的保护规则保持生效。

本地普通输入、剪贴板同步和私密互传不需要配置这些云服务。测试有道时使用独立有道测试入口，不用其他服务的连接测试结果判断有道是否可用。

安卓打开键盘工具栏的中英互译后，长按中间的原文输入框，点击「粘贴」，即可翻译剪贴板里的文字；也可继续手动输入。点确定保留译文，点取消撤回。本次原文最多 5000 个字符，超出部分不会写入。

## 安卓豆包语音

在「语音识别」页选择「火山引擎 · 豆包语音」，填写该服务的 API Key。保留两种 2.0 模型：流式识别边说边显示文字；录音文件识别在松手后上传并等待结果。选择已在豆包语音控制台开通的模型，识别失败不会自动换模型。

两端需要分别登录、分别配置。账号凭据和密钥只在本机保存；会员凭据和有道密钥加密保存，不随普通配置导出。


## 查看来源与项目地址

Windows 设置的「关于」页，在版本下方注明本软件是基于青简输入法改版的猛人输入法。页面分别提供青简官网、青简 GitHub 和猛人输入法 GitHub 三个入口。窗口、侧栏和关于页使用统一的天马标志。
