在 macOS、Windows 与 Android 之间互传复制的文字和图片：一边复制，另一边直接粘贴。本页的局域网直连只在设备之间加密传输，不经过服务器；猛人另行开启中转时会经自有服务器转发密文。这是实验功能，默认关闭，Linux 还不支持。

本页主要说明局域网普通同步。猛人 Windows/Android 另有自建公网中转、图片系统剪贴板和私密输入，见 [猛人同步说明](../help/mengren-relay.md)；这些功能不表示 macOS/Linux 已接入猛人中转。只有局域网直连不经过服务器，启用公网回退时由自己的中转转发密文。

## 打开与配对

1. 两台设备都打开同步：
   - macOS、Windows：「设置 → 实验功能」打开青简剪贴板和「局域网同步」。
   - Android：「设置 → 局域网同步」。
2. 打开设备页：电脑上按快捷键呼出剪贴板面板（缺省 macOS 是 ⌘⇧V，Windows 是 Ctrl + Alt + V），点「设备」；Android 就在刚才那一页。
3. 一台点「显示配对码」，另一台在「附近的设备」里点对方，输入这 6 位数字。

配对码 2 分钟内有效，输错一次就作废，重新生成一个就好。「附近的设备」里没有对方时，用「手动输入地址」，写对方的 IP 地址和端口，比如 `192.168.1.5:53319`。

只需配对一次。设备名可以改；没起名时会有一个随机的名字，配对后在别的设备上显示的就是它。设备名和电脑名（或手机型号）在同步打开时局域网里的设备都看得到，不要写隐私内容。

## 同步什么

- 普通历史同步文字与图片。Windows 和 Android 的文件互传需要单独开启。
- 收到的普通内容进历史，最新内容也会放上系统剪贴板。猛人 Android v0.3.6 起图片同样提供给系统剪贴板，需目标应用支持图片粘贴；上游旧版 Android 的图片使用面板入口。
- 手动删掉一条，其他设备也会删掉。超出最多保留条数被清掉、或者清空本机历史，只影响本机。
- 对方不在线时不算失败，上线后自动补传。
- 每台设备同步的是自己的整个历史，里面也有从别的设备收到的内容。所以 A 和 B 配对、B 又和 C 配对时，A 复制的内容会经过 B 到 C，C 的也会经过 B 到 A（B 要在线）。A 和 C 之间并没有配对，设备页里也看不到对方。不想让内容传到 C，就别让 B 同时和两边配对。

以上补传和转发规则仅适用于普通历史。猛人私密内容要求直接配对、在线投递，不进普通历史，不经第三台设备转发或离线补传。

## 局域网文件复制粘贴（Windows 和 Android 0.4.8 起）

**一次设置。** 把两台设备接到同一 Wi-Fi 或以太网，按本页步骤完成配对。Windows 在「设置 → 实验功能」开启「局域网文件复制粘贴」，按「Ctrl + Alt + V → 设备」，在对方名称旁点「允许文件」。Android 在「猛人输入法 → 设置 → 局域网同步」开启同名开关，在对方名称下打开「允许与此设备互传文件」。两端都选中对方后，平时复制即可。每台接收设备都需与发送方直接配对。关闭开关或取消选择会停止相应传输。

| 在哪里操作 | 怎么做 |
|---|---|
| Windows 发送 | 在资源管理器选中一个文件，按 Ctrl + C。复制 JPG、PNG 文件会保留原图，截图仍按原图片设置处理。 |
| Windows 接收 | 等待送达后，在资源管理器打开目标文件夹，按 Ctrl + V。若期间复制了别的内容，到「剪贴板面板 → 设备 → 打开接收文件夹」取回。每次接收都有独立目录。 |
| Android 发送 | 在文件管理器复制一个文件。若复制后仅能在同一文件管理器内粘贴，改点「分享 → 猛人输入法 · 局域网发送」，会直接发往已选设备。复制路径文字按文字处理。 |
| Android 接收 | 在支持文件粘贴的应用使用「粘贴」。也可打开猛人键盘的「剪贴板」，点列表顶部的「保存到下载」。如需找之前的文件，在「设置 → 局域网同步」顶部按文件名点「保存到下载」。Android 8、9 会打开系统保存位置选择器，请选「下载」。 |

**单个文件小于 300 MB。** 可传 0 到 299,999,999 字节，恰好 300,000,000 字节即超限。每次选一个普通文件，文件夹请先打成 ZIP。文件按原名、原始内容交付，扩展名可以未知或为空。安装包不会自动运行，压缩包不会自动解压；要跨系统保存，文件名需符合两端命名规则。

文件仅尝试当次局域网直连。当前版本需要同一链路的 IPv4 网络。访客网络隔离、切换到蜂窝网络、权限失效或对方休眠都可能导致失败，恢复后请重新复制。即使开启文字图片公网中转，文件也不会进入中转、历史补传或经第三台设备转发。旧版仍能同步普通内容，文件互传需双方升级。

手机需使用猛人作为默认输入法并保持进程运行。锁屏时系统可能限制剪贴板或网络，进程被回收期间错过的文件复制不会重放。收到的完整文件会保留约 7 天。需长期保留时，请粘贴到目标文件夹或保存到下载。

## 连接状态

| 显示 | 含义 |
|---|---|
| 已连接 | 最近真的连上过 |
| 正在连接… | 还没有结果，正在试 |
| 连不上 | 最近一次连接失败；对方可能关了同步、关机或换了网络。显示的时间是上次同步的时间 |

## 霓虹灯

收到内容时，屏幕边缘（Android 上是键盘边缘）亮一圈光。传得快时颜色从蓝变青再变紫，成功转绿后收起，失败转红；电脑上失败时还会闪两下，分不清红绿也看得出来。发送方只在发送失败时才亮红色。可以在同步的设置里关掉。Windows 上全屏游戏和演示时不显示，macOS 上一直照常显示。

## 解除配对

在设备页对方那一行点「解除配对」。只要一边解除就行：对方下次连过来时会被告知，它那边也会自动去掉，不用两边各点一次，解除时对方不在线也一样。

## 常见问题

- **剪贴板面板收起后还同步吗？** 同步。电脑上只要剪贴板程序在运行就行：Windows 看托盘，macOS 看菜单栏有没有剪贴板图标。
- **手机上没及时收到？** Android 只在输入法或青简 App 运行时同步，系统把它们清掉后，下次弹出键盘时会补上。
- **配不上、连不上？** 确认两台在同一个网络；Windows 第一次打开同步时如果弹出防火墙提示，要允许专用网络；macOS 开着防火墙时会问是否允许「青简剪贴板」接受传入连接，要点允许；访客网络或开了「AP 隔离」的路由器可能禁止设备互连。

## 猛人 0.4.0 小窗口与自定义短语

Windows 历史面板采用约 420×520 逻辑像素的小窗口，在当前工作区内随系统缩放。内容竖排、滚轮上下查看，短文卡片减少留白；长文和图片只限制预览，原内容不截断。点「自定义短语」可查看另存的短语，带输入码的也能直接在输入法中调用。

Windows / Android 0.4.0 在设备同步开启且直接配对后自动合并新增短语，也有「立即同步」入口；合并与隐私规则见 [自定义短语](phrases.md#windows--android-跨设备同步猛人-040)。
