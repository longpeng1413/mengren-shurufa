# 0.4.4 安卓上滑符号与候选间距

2026-11-08：用户要求将两项安卓个性化一起完成，沿用完整验证后发布授权，保留签名、资料和配对。本轮不扩大到数字前缀短语等另行排期项目。

## 实现

- 在键盘手势页提供逐字母编辑，最多 8 个 Unicode 码点，不允许空白/控制字符；留空恢复当前语言默认，全部恢复前有确认。
- 配置在本机设置中逐字母保存；重建键盘时替换角标，保留双拼声韵母、键宽和特殊 Shift 行为；九宫格不改。
- 在外观页提供 2–24 dp 每侧留白，默认 8 dp；预览和实际候选条使用同一 Rust 主题布局，点击区域与文字同时生成，不压缩字体。
- 预览缓存限制为 64 项，避免连续调整多个主题/间距时无限保留位图。
- 两端同步升级 0.4.4；代码与包通过校验后公开发布，旧交付包送回收站。

## 验证边界

自动验证逐字母覆盖、Unicode 输入边界、默认回退、双拼字段和保留手势；在全部内置主题的深浅色下检查候选宽度、边界和高度。真实手机的上滑手感、设置页预览和候选点按需用户安装后确认，不标记为已经真机验收。
