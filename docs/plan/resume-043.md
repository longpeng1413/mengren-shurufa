# 0.4.3 名称、图标与复制验证码

2026-11-08：用户要求全面检查用户可见名称和图标，并在安卓复制短信验证码后提供可点击填入的提示。沿用完成验证后发布新版的既有授权，保留原签名、设置和配对。

## 本轮实现

- Android 保存/分享日志、数据备份及 Windows 新旧设置的日志包统一为 `mengren-shurufa-logs-日期.zip`、`mengren-shurufa-data-日期.zip`（数据备份为安卓）。既有日志文件不批量改名。
- 补齐外语界面、托盘/窗口标题、导出的生词网页和独立剪贴板安装器名称；Windows 四个可执行程序补齐猛人产品名/文件描述。
- 核对 18 个活动品牌图片/图标目标与既定天马猛素材相同，确认 Android 自适应/单色图标、工具栏/首页/关于，以及 Windows 注册/托盘/窗口/安装图标的引用。功能符号图标继续表达各自功能。
- 安卓从用户已经复制的内容提供候选栏按钮。纯 4–8 位数字保留前导零；含验证码语义的短短信只提取唯一数字码，歧义不猜测。Android 16 可参考系统已有 OTP 分类，不申请读取短信权限。
- 点击前核对复制时间和内容，切换输入框可继续显示未使用的新内容；使用、关闭、复制满五分钟后停止提示。只有键盘显示、设备解锁且未组词/编辑翻译时提供；被遮挡的点击有可理解的反馈，不静默放行。
- 标记敏感的内容不显示正文，可点按钮填写；保留原敏感内容私密发送规则。候选本身不新增历史或网络发送，普通剪贴板的记录和同步仍按原设置执行。

## 保留边界与验收

上游署名、来源、青简官网/GitHub 保留，旧版关于也补齐猛人项目链接。crate/Kotlin 包名、JNI、CLSID、系统数据路径与旧安装的内部文件名保留，避免因改显示名称导致资料/身份丢失。

源码识别、候选生命周期与构建验证分别记录；真实短信通知“复制验证码”、各手机目标应用的填入表现仍需安装新版本确认。不把魅族重启后 0.4.2 可填入的反馈扩大为新功能真机已验收。此前休眠豁免、API 长期上限和占用展示不开发、数字前缀短语后续处理等取舍继续有效。
