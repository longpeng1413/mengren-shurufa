# 猛人输入法改版说明

猛人输入法基于 [青简输入法](https://github.com/qingjian-team/qingjian) 开发，保留原有版权、GPL-3.0-or-later 许可证和数据来源声明。上游基线为 `ec1bb853a9854c2394b45858943933ee6a897c50`。

改版包含猛人品牌资源、安卓删除手势、有道快捷翻译、ChatGPT 会员授权通道、豆包语音的两种 2.0 识别方式，以及安卓多家云服务配置和按功能选择服务。使用方式见 [会员与有道翻译](../user/cloud/mengren-services.md)。云服务和语音服务需由使用者自行配置。

后续计划包括桌面端多服务界面、中转同步和私密内容投递。这些规划尚未全部完成，不能据此认定已有可用功能。

公开源码不包含维护者个人的服务器资料、本机开发笔记、早期设计素材、运行凭据、编译缓存和安装包。`mengren/export-public.py` 从当前工作区导出独立源码快照，不复制原开发仓库的 Git 历史；导出文件的 SHA256 清单另存在本机输出目录旁。构建方法仍以 CLAUDE.md、各平台 README 和构建脚本为准。
