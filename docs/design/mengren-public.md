# 猛人输入法改版范围

产品版本为 v0.4.0（2026-11-07）。猛人输入法基于 [青简输入法](https://github.com/qingjian-team/qingjian) 开发，上游基线为 `ec1bb853a9854c2394b45858943933ee6a897c50`；保留原版权、GPL-3.0-or-later 及各组件和数据的许可声明。

2026-11-07 用户确认 v0.3.8 魅族到华为和台式机私密互传通过；新笔记本尚未配对，不能仅凭加入局域网判断可同步。0.4.0 修复 Windows 配对码小键盘输入（用户确认正常），统一两端「自定义短语」名称并同步新增短语，电脑剪贴板改为紧凑竖排小窗口。历史故障见 [问题分析](../notes/private-transfer-037-review.md)，自动验证与用户真机确认分别记录。

## 当前取舍与剩余工作

翻译目前使用有道。桌面多服务分配扩展、新增语音入口和悬浮窗改造暂缓。接下来先完成真实设备反馈，再处理私密输入兼容性、更新安装和 P5 的统计保留/异常清理核查，详见 [当前待办](../plan/todo.md#猛人当前进度与待办)。

上游 macOS/Linux 路线图与旧发布说明保留为来源及历史资料，不表示猛人改版已经覆盖所有平台。密码框自动填入依据系统控件标记，不提供密码管理器的账号/域名匹配，也不是完整系统 Autofill provider。

## 公开与发布边界

公开源码不含维护者个人服务器资料、本机开发笔记、早期设计素材、凭据、签名私钥、编译缓存和安装包。`mengren/export-public.py` 导出独立源码快照，不复制原开发仓库历史；流程见 [发版说明](../notes/release.md)。

用户已明确授权本轮完成后发布 v0.4.0，使手机和电脑可通过检查更新进行定向复测；旧 v0.3.7 标签和附件保留。按原签名、源码隐私审查和更新索引验签流程交付，不把自动验证当作真机验收。
