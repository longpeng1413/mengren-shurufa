# 公网剪贴板中转

客户端实现位于 `qingjian-clipboard-sync::relay`，独立服务入口在 `mengren/relay`。参考猛人快传的公网模式：用户自有 VPS、WSS 加访问令牌、只在线转发、不存消息；不复用快传协议、口令或服务进程。

## 连接与身份

- 登记：`/v1/clipboard/register/<设备公钥十六进制>`。服务器定期推送在线编号，通过心跳发现断线；客户端约三秒后重连。服务端不接收设备名。
- 发起：`/v1/clipboard/connect/<自己编号>/<目标编号>`。服务端生成随机会话能力标识，通知在线目标；八秒未接通清理等待项。
- 接入：目标连接 `/v1/clipboard/accept/<目标编号>/<会话标识>`，匹配等待项后双方收到 `ready`，开始转发二进制字节流。
- 所有 WebSocket 握手要求 Bearer 令牌。公网 URL 必须 WSS，无 userinfo、查询串；仅本机数字回环地址允许 WS 集成测试。
- 外层路由信息不作为身份认证。内部仍是原有六位码 SPAKE2 + Noise 配对；之后使用已配对公钥验证。主动配对还检查接通的 Noise 公钥是否符合目标编号，恶意中转不能静默换设备。

## 内容与限制

原同步对账协议和存储接口不变。中转路径使用 `BoundedReplica` 过滤清单、读取和接收，接受小于 100,000,000 字节的文字或图片；不伪造图片删除标记，不改变本地图片。接收结果必须与清单 ID、内容摘要一致，设备处理完成后才推进原有对账流程。

上限：16 个在线设备、16 个等待会话、48 条服务端连接；每个客户端最多四条同时接入的连接。二进制帧最多 64 KiB，单次连接转发最多 512 MiB、持续最多十分钟、空闲最多三十秒。原协议对消息分块；中断后由下轮对账补齐尚未处理的数据。服务端无持久状态，客户端保留原配对身份及历史。

局域网连接超时三秒，失败后在目标登记在线的前提下尝试中转。中转开启时每五秒补一次对账，新复制和对方上线立即触发；首次回退时间不等于已连接后的推送延迟。状态记录最近成功使用的实际路线。解绑拒绝保留原语义，不经中转重新授权设备。

## 平台与部署

Windows 设置程序将令牌放入当前用户 DPAPI，普通配置只保存 URL、开关与无秘密的变更标记；剪贴板壳读取后作为 `SyncOptions.relay` 注入。安卓使用现有 Keystore 加密，JNI 只在内存传递。`RelayConfig` 的序列化跳过令牌，Debug 始终遮盖。

默认关闭，不内置作者的地址、IP 或访问令牌。TLS 使用 rustls + Mozilla 根证书，逐个尝试 DNS 返回的 IPv4/IPv6 地址；保持原有局域网发现与监听。不额外启动安卓常驻前台服务。

服务进程只监听回环地址，前置独立 Caddy。443 已被其他服务占用时可使用 8443，仅为 ACME HTTP 验证开放 80，不改动已有代理端口。Caddy 只转发中转与健康检查路径，日志过滤掉请求信息。环境文件 0600，使用 DynamicUser、内存与连接上限。真实部署地址和操作记录只留私有运维资料。

本地集成测试使用两个无 LAN 地址的真实同步服务，覆盖错误配对、正确配对、双向文字和图片、中转重启补传和解绑；另有明确运行的 release 测试覆盖 99,999,999 字节图片和三台设备。`mengren-ime-relay` 的 `probe` 二进制从环境变量取得临时参数，仅使用合成数据验收真实 WSS；不读取用户剪贴板、不输出凭据。手机移动网络及系统休眠仍需真机验收。

## 私密通道

认证后的能力查询 opening=4；只有已配对公钥返回明确接收能力才使用 opening=5。两条连接均复用 Noise 公钥验证，不能根据中转提供的名字或型号判断接收权限。兼容旧客户端，旧设备拒绝未知 opening，不取消配对。

私密消息仅在本次后台任务中持有，不进入 Replica、命令队列、JSON 历史或事件正文。单次发送最多 15 秒内开始各目标尝试；已发出后不切换路线重试，确认丢失视为失败。最大正文 16 KiB，加八字节绝对到期时间，接收端最多保留两分钟。Secret 与受控明文缓冲用 zeroize 覆盖，Debug 遮盖。Android/JNI 和系统本身的字符串副本不承诺可原地覆盖。

PrivateVault 单槽、取用即清除。监听线程每 250 ms 回收过期内容；Windows WTS/电源消息直接撤销保险箱，阻止迟到网络包重新填充。关闭接收、解绑和服务 Drop 清理。Windows Unicode SendInput 先等修饰键松开、复核前台窗口，失败不回退到剪贴板。默认与原 Ctrl+Alt+V 共用注册，有私密槽才优先消费；另可录制独立快捷键。

Android 普通图片捕获以 64 KiB 缓冲暂存于自己的 clipboard-import 目录，JNI 只接收路径并限长读取，结束删除暂存文件；私密内容从不走这个路径。接收 wire 解码复用消息 Vec，避免额外复制整张大图。JNI 图片完成事件只传历史图片路径，系统通过只读 ContentProvider 提供图片；监听忽略自己 provider 的 URI，避免回声。


## 猛人 v0.3.7

v0.3.7 私密收发扩展到两端，服务协议不变。接收权限和屏幕可用性提交与入槽串行，在网络确认前释放锁。私密发送不等待可能过期的在线列表，而由中转按即时注册状态接通，不存离线消息。自动填充、焦点授权和调研依据见 [private-transfer.md](private-transfer.md)。
