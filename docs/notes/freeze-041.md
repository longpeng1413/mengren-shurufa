# 0.4.1 冻结审计与原计划对照

核查日期：2026-11-07。按用户要求，合并安卓中文设备名修复、更新说明后发布 0.4.1，随后冻结版本并暂停开发。冻结是停止继续投入，不等于原设计所有目标或所有真机验收已经完成。后续只有用户明确要求恢复时再继续。

## 核查依据

对照本机保存的 2026-11-06 原始 v0.2 设计备份、当前私人设计、用户后续决定、当前源码及 0.3.8/0.4.0 发布证据。原始私人资料及服务器信息不公开。公开的当前规格为 [改版范围](../design/mengren-public.md)、[私密流程](../design/private-transfer.md)、[中转](../design/clipboard-relay.md)、[更新](../design/update.md)和[短语规则](../user/personalize/phrases.md)。上游路线图不是本轮承诺的待开发清单。

## 尚未完成的工程项

1. **API 用量长期保留上限。** `qingjian-predict/src/usage/hours.rs` 仅在超过 256 KiB 后合并相同小时，不淘汰旧日期、不设硬总量上限。P5 未完成，累计计数语义须在恢复开发后继续保留。
2. **异常清理的完整核查。** Android 启动清理自己的图片导入暂存；更新失败/取消会清理残片，下一次下载清理超过一天的受管包和残片。尚未证明所有异常退出与所有缓存目录都覆盖，也不是持续后台统一清理。
3. **剪贴板占用展示。** 条数上限和清空入口已存在；原设计提到的统一存储占用展示尚未完整交付，不把条数控制说成字节总量限制。
4. **设备改名后旧配对名称刷新。** 本机可保存中文，新发现/新配对支持 Unicode 名称；已有配对记录主要保留配对时名字，尚未提供统一的认证改名传播协议。改名不改变设备公钥，不影响原配对和同步；不要以反复解绑作为必需步骤。
5. **既有橙色光圈反馈。** 没有足够证据确认仅是同步提示，亦没有完成多屏或手机进程退出的定位，不标记已解决。
6. **运维一键清理集成。** 已有只读 `report.sh` 可查看新增服务状态和资源；未核实原计划的一键清理工具已集成该报告。本轮不变更服务器、端口、防火墙或线上服务。

这些项目随冻结保留，不在本轮新增功能，也不以文档更新代替实现。

## 文档修订与历史边界

修正当前说明中的 0.3.7 未复测、等待准备、15 秒全局截止、纯本地不联网、所有文件均为纯文本或均原子替换等过时表述；补齐短语持久化与隐私边界、中文命名、命名刷新限制和冻结状态。私人设计正文重写为当前规格，原始备份保留。旧 Release、CHANGELOG 和带日期的事故原文保留，仅加后续状态说明；上游其他平台资料明确标为基线，不全库机械替换版本号。

## 冻结后的使用与恢复

更新到 0.4.1 后继续使用即可。优先验收中文设备名和新增短语同步；其他待验收项见[测试清单](../user/help/mengren-testing.md)。新反馈可以记录，只有用户要求修复或恢复开发时再开工。开发缓存保留，不删除安装目录、用户资料、配对身份、原签名或历史发布。
