# 0.4.3 用户可见品牌核查

本轮检查活动运行入口，不根据内部文件名推断图标内容。`python mengren/audit-brand.py` 会调用幂等换牌检查，核对 18 个品牌图片/ICO 目标与 `mengren/brand` 既定素材的字节一致性，并检查两种安卓资源、桌面多语言标题、三个日志导出入口与四个 Windows 资源描述。

| 入口 | 结果 |
| --- | --- |
| 安卓保存/分享日志与数据备份 | 修正 `qingjian-logs` / `qingjian-data` 默认文件名 |
| 安卓桌面、自适应、单色、输入法列表、工具栏、首页、关于 | 活动资源均引用现有天马猛素材，旧前景回退资源也已替换为天马猛别名，原签名和应用 ID 保留 |
| 安卓系统剪贴板内容标签 | 同步和翻译复制标签改用猛人资源文字 |
| Windows 新旧设置日志包 | 默认文件名统一；历史日志内容和内部模块名不改 |
| Windows 设置、Server、剪贴板、旧版设置 EXE | 嵌入图标源一致，并补齐 ProductName / FileDescription / CompanyName |
| Windows TSF 注册、安装器、深浅色托盘 | 既有猛人 ICO 引用正确，保留 CLSID 和内部文件名 |
| Windows 旧版窗口与辅助窗口、外语界面、导出网页 | 补齐名称，旧版关于保留来源并增加猛人 GitHub |
| 独立剪贴板安装器 | 修正产品名和发布者，内部数据目录保持兼容 |

`qingjian` 作为 crate、JNI、Kotlin namespace、数据路径以及历史日志模块名时属于兼容标识，不做全局替换。青简的版权、词库和模型来源、上游链接继续保留。未在当前 Windows/Android 中使用的上游其他平台素材不作为运行图标替换。
