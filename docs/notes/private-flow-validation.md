## 本地改动

- 安卓应用进程持有复制监听；先启用同步再监听，不要求键盘展开；IME 销毁不清进程私密槽。
- 敏感复制受理后才写独立时间戳；失败未受理可重新捕获，已受理不重放，超过两分钟的源复制不自动发送。不保存密码或其摘要。
- 两端移除空槽等待切换与等待提示；电脑输入共用许可，消费本次内容后即使失败也不误清后来新到内容。
- 每轮最多四个并行目标，不用全局十五秒时间切掉后续目标；逐目标接收确认与最终确认台数分开，ACK 后收尾失败仍记已确认。事件不带正文，网络协议兼容原中转。
- 安卓单条可替换 Toast 与重复去重，旧 poller 回调失效；电脑气泡限频及实时投递，设备页显示逐设备状态。
- 可选密码框自动填入的新配置默认关闭，已有保存选择保留。

## 验证记录

结果以本机 `target/private-flow-final-tests.log`、`target/private-flow-settings-final.log`、`target/private-flow-clippy-final.log`、`target/private-flow-android-final.log`、`target/private-flow-android-native.log` 和 `target/private-flow-check.json` 为准，均为构建缓存，不公开原始环境资料。

首次沙箱测试的 Windows DPAPI 返回系统找不到文件，正常用户环境重跑通过。健康检查测试出现 Windows 回环连接重置，正常环境单测曾通过、整组仍偶发失败；已将测试改为按 HTTP Content-Length 读取完整响应，不再依赖 EOF，不改线上服务。一次并行普通配对测试超时，串行回归通过；不据此断言超时原因已经定位。设置帮助锚点测试发现之前文档整理造成的标题失配，已恢复输入日志、运行日志、检查更新的标题。保留首次失败日志，不宣称从未失败。

自动检查覆盖三台逻辑设备六方向私密投递和逐目标确认、禁收/锁定撤销、不入普通副本/正文文件、输入许可并发竞争、失败不误清新槽，以及 Kotlin 源复制去重与过期。Kotlin 编译与 JNI/Rust 测试分开，未运行正式 APK 打包任务。

最终结果：相关 Rust 模块合计 309 项通过，2 项既有大型/联网测试保留忽略；其中同步模块最后单独回归 35 项通过、设置模块修正标题后 28 项通过。Android Kotlin 4 项单元测试通过，完整 Kotlin/资源编译及 ARM64 NDK 本地库编译通过。相关模块 clippy（所有目标、警告视为错误）、全仓格式检查通过。文档相对文件链接、frontmatter、公开说明私人地址扫描通过，源码范围与文档更新前基线比对无无关变更。早期失败和修正后的单独通过记录均保留。
